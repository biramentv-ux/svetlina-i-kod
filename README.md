# Светлина и код

Безплатна школа на български за VJ, програмиране, изкуствен интелект и reverse engineering.
Цялата школа – всички курсове, пълни уроци, тестове и проекти – се сглобява в **един HTML файл**,
който работи без сървър, без регистрация и офлайн.

- Курсове: 16 в четири пътеки – Визия на живо, Изкуствен интелект, Reverse engineering и Код от нулата
- Напредъкът се пази само в браузъра на ученика; няма аналитика и бисквитки
- Уроците могат да се слушат с гласа на устройството (Web Speech API)
- Светла и тъмна тема, търсене (`/` или Ctrl+K), съдържание и напредък при четене

## Сглобяване

Нужни са Node.js 22 и pnpm.

```bash
pnpm install
pnpm build          # същото като: bash scripts/build.sh
```

Резултатът е `bundle.html` (и копие в `deploy/index.html`) – един самостоятелен файл.
Променливата `SITE_URL` задава каноничния адрес (по подразбиране `https://shkola.dyrakarmy.eu/`).

## Структура

| Път | Съдържание |
|---|---|
| `src/App.tsx` | цялото приложение: начална страница, каталог, курс, урок, търсене, слушане |
| `src/index.css`, `DESIGN.md` | дизайн система: токени за светла и тъмна тема, компоненти |
| `src/courses.ts` | курсове, модули, уроци и времетраене |
| `src/content/c*.ts` | кратки резюмета, ключови точки, задачи и тестове към всеки урок |
| `lessons/<курс>/m<модул>-l<урок>.md` | пълните уроци в Markdown |
| `lessons/BRIEF*.md` | правилата, по които се пишат уроците |
| `scripts/` | сглобяване: шрифтове, уроци, Parcel и вграждане в един файл |
| `vendor/fonts/` | шрифтовете (OFL), вградени като base64 |

Нов урок: добави заглавието в `src/courses.ts`, резюмето в `src/content/`, а пълния текст като
`lessons/<slug>/m<i>-l<j>.md`. `scripts/gen-lessons.mjs` го вгражда при следващото сглобяване.

## Публикуване

Workflow-ът `.github/workflows/deploy.yml` се пуска при всеки push в `main`:

1. Сглобява школата.
2. Публикува я в **GitHub Pages** (включи Settings → Pages → Source: GitHub Actions).
3. Пресмята **IPFS CID** и CAR файл с `ipfs/ipfs-deploy-action`. CID-ът се вижда в обобщението
   на изпълнението, а CAR файлът е прикачен като artifact.

Подробно – в [`deploy/README.md`](deploy/README.md): GitHub Pages, IPFS (закачане и DNSLink),
Hugging Face Spaces и собствен домейн.
