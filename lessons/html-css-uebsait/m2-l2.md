> **Цел на урока:** да управляваш цветовете и размерите на сайта от едно място с CSS променливи, да добавиш тъмна тема и да направиш движението плавно, без да пречиш на хората, които предпочитат по-малко анимация.

## Какво ще научиш
- Как се декларират и ползват CSS променливи (custom properties) и как се наследяват
- Как да направиш тъмна тема с `prefers-color-scheme` и с ръчно превключване
- Как работи `transition` и кои свойства е добре да се анимират
- Как се пише анимация с `@keyframes` и `animation`
- Как `prefers-reduced-motion` пази хората, на които движението вреди

## CSS променливи

До сега си повтарял един и същ цвят на десет места. Ако шефът реши, че синьото е по-светло, ще го менявеш десет пъти и ще пропуснеш едно. CSS променливите решават това: дефинираш стойността веднъж, ползваш я навсякъде.

Името започва с две тирета, а стойността се чете с `var()`:

```css
:root {
  --bg: #ffffff;
  --text: #1a1a1a;
  --accent: #0b4fb3;
  --radius: 10px;
}
.btn { background: var(--accent); border-radius: var(--radius); }
```

`:root` е самият документ (същото като `html`, само че с по-висока специфичност), затова променливите, декларирани там, са достъпни за всички елементи. Променливите **се наследяват** като останалите свойства и могат да се презапишат локално:

```css
.karta-danger { --accent: #b3261e; }
```

Всичко вътре в `.karta-danger` ползва червения акцент, а останалата страница – синия. Това е мощна разлика спрямо препроцесорните променливи в Sass и подобни инструменти: тези на CSS живеят в браузъра, могат да се променят при `media` условия, с клас или от JavaScript, и страницата реагира веднага.

Функцията `var()` приема втори аргумент – стойност по подразбиране: `var(--accent, #0b4fb3)`. Ползва се, когато променливата не е определена. Променливата не се ползва в имената на свойствата или в самите media условия, а само като стойност.

Добра практика е да именуваш променливите по роля (`--bg`, `--text`, `--accent`), а не по цвят (`--blue`). „Синьо“ няма да е синьо в тъмната тема, а ролята „акцент“ остава вярна.

## Тъмна тема

Много системи имат настройка за тъмен режим. Браузърът я предава на страницата и можеш да я прочетеш с media query:

```css
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #14181f;
    --text: #e8ecf3;
    --accent: #8aa4ff;
  }
}
```

Не променяш нито едно правило за елементите – сменяш само стойностите на променливите. Ето защо ролевите имена са толкова полезни.

Редът `color-scheme: light dark;` в `:root` казва на браузъра, че страницата поддържа и двете схеми. Тогава стандартните елементи (полета, скролбарове, фонът по подразбиране) също се нагаждат, а не остават светли на тъмен фон.

Помни от урока за достъпност: контрастът трябва да е достатъчен и в двете теми. Светлосиньото `#8aa4ff` върху тъмния фон `#14181f` дава около 7,5:1, докато тъмносиньото `#0b4fb3` върху същия фон дава само около 2,4:1. Затова **акцентът е различен** в двете теми, а текстът върху бутона също се обръща (`--on-accent`).

**Ръчен превключвател.** Някои хора искат да изберат тема независимо от системата. Тогава ползваш атрибут на `<html>`, например `data-theme="dark"`, и правило:

```css
:root[data-theme="dark"] {
  --bg: #14181f; --text: #e8ecf3; --accent: #8aa4ff;
}
```

Самият атрибут се сменя с малко JavaScript (в курса „JavaScript за уеб“) и обикновено се запазва в `localStorage`. В този урок само показваме, че CSS част е същата: нов набор променливи.

## Преходи

Без прехода един бутон при `:hover` сменя цвета си мигновено. `transition` казва на браузъра да промени стойността плавно за определено време:

```css
.btn {
  transition: transform .25s ease, background-color .25s ease;
}
.btn:hover, .btn:focus-visible { transform: translateY(-3px) scale(1.04); }
```

Прехода описваш в **изходното** състояние (`.btn`), а не в `:hover`, за да работи и при връщане. Частите му са: кое свойство (`transform`), колко време (`.25s`), крива на скоростта (`ease`, `linear`, `ease-in-out`) и по желание забавяне. Можеш да изброиш няколко свойства със запетая. Свойството `all` работи, но анимира всичко включително неща, които не си очаквал – избирай конкретно.

**`transform`** променя външния вид без да премества съседите: `translate` (преместване), `scale` (мащаб), `rotate` (завъртане). Браузърът обикновено ги обработва по-евтино, отколкото промяна на `width`, `height`, `top` или `margin`, които налагат ново подреждане на страницата. Затова за движение предпочитай `transform` и `opacity`.

Не всичко се анимира: преходът работи само между стойности, между които браузърът може да интерполира (числа, цветове, дължини). `display: none` към `block` не е плавен.

Ето реален тест. Задавам на бутона същото преместване и четене на `transform` на всеки около 90 милисекунди:

```
none -> matrix(1.02303, 0, 0, 1.02303, 0, -1.7276) -> matrix(1.03699, 0, 0, 1.03699, 0, -2.77448) -> matrix(1.04, 0, 0, 1.04, 0, -3)
```

Матрицата `matrix(a, 0, 0, d, tx, ty)` тук значи мащаб `a` и преместване `ty`. Виждаш как мащабът минава от 1 през 1,023 и 1,037 до 1,04, а преместването – от 0 през −1,7 и −2,8 до −3 пиксела. Това е прехода – стойностите се променят плавно, а не наведнъж.

## Анимации с @keyframes

Когато искаш движение, което не зависи от състояние – пулсиращ бутон, индикатор за зареждане – ползваш анимация. Първо описваш кадрите:

```css
@keyframes puls {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }
}
```

После я прикачаш към елемент:

```css
.pulse { animation: puls 1.2s ease-in-out infinite; }
```

Съкратеният запис съдържа име, времетраене, крива и брой повторения (`infinite` е безкрайно). Можеш да добавиш `animation-delay`, `animation-direction` и други. Разликата с прехода е в това, че анимацията има свои собствени кадри и може да върви сама, а прехода се задейства от промяна на състояние.

## Уважение към намаленото движение

Безкрайно пулсиране или голямо плъзгане може да е неприятно, да разсейва или да причинява световъртеж на хора с вестибуларни проблеми или чувствителност към движение. Операционните системи имат настройка „намали движението“, а браузърът я предава през `prefers-reduced-motion`.

Най-безопасният подход е да **добавяш** движение само когато потребителят не е поискал по-малко:

```css
@media (prefers-reduced-motion: no-preference) {
  .pulse { animation: puls 1.2s ease-in-out infinite; }
}
@media (prefers-reduced-motion: reduce) {
  .btn { transition: none; }
}
```

Така анимацията изобщо не съществува за този, който я е изключил, а за преходите – изрично ги изключваш при `reduce`. Не е нужно да махаш всичко: промяната на цвят е спокойна; тревожат ги по-скоро голямото преместване, въртене и повторение.

## Стъпка по стъпка

1. Прегледай CSS-а си и подчертай всички цветове, които се повтарят. Дай им роли.
2. Декларирай ги като променливи в `:root` и замени повторенията с `var(--име)`.
3. Добави `color-scheme: light dark;` и блок `@media (prefers-color-scheme: dark)` със стойностите за тъмна тема. Провери контраста в двете теми.
4. Добави `transition` на бутоните и връзките и стил за `:hover` и `:focus-visible`.
5. Добави по желание една малка анимация с `@keyframes`, но само в `@media (prefers-reduced-motion: no-preference)`.
6. Тествай: в инструментите за разработчици можеш да емулираш тъмна тема и намалено движение (в зависимост от версията – в менюто за допълнителни инструменти, раздел за рендиране). Така не променяш системните настройки.

## Пример от практиката

Да кажем, че страницата на пекарната има карта с бутон „Запиши ме“. Ето пълния пример (`tema.html`, съкратен до стила):

```html
<style>
  :root {
    color-scheme: light dark;
    --bg: #ffffff;
    --text: #1a1a1a;
    --card: #f1f4f9;
    --accent: #0b4fb3;
    --on-accent: #ffffff;
    --radius: 10px;
  }
  @media (prefers-color-scheme: dark) {
    :root {
      --bg: #14181f;
      --text: #e8ecf3;
      --card: #1e2430;
      --accent: #8aa4ff;
      --on-accent: #0d1220;
    }
  }
  body { background: var(--bg); color: var(--text); font-family: system-ui, sans-serif; margin: 0; padding: 2rem; }
  .karta { background: var(--card); border-radius: var(--radius); padding: 1.5rem; max-width: 24rem; }
  .btn {
    background: var(--accent); color: var(--on-accent);
    border: 0; border-radius: var(--radius); padding: .7rem 1.2rem; font: inherit; cursor: pointer;
    transition: transform .25s ease, background-color .25s ease;
  }
  .btn:hover, .btn:focus-visible { transform: translateY(-3px) scale(1.04); }
  .btn:active { transform: none; }
  @media (prefers-reduced-motion: no-preference) {
    .pulse { animation: puls 1.2s ease-in-out infinite; }
  }
  @keyframes puls {
    0%, 100% { transform: scale(1); }
    50% { transform: scale(1.06); }
  }
</style>
```

Пуснах страницата в Chromium през Playwright при три настройки на системата (светла тема, тъмна тема, тъмна тема с намалено движение) и прочетох изчислените стойности:

```
light no-preference  {"fon":"rgb(255, 255, 255)","tekst":"rgb(26, 26, 26)","buton":"rgb(11, 79, 179)","animacia":"puls"}
dark no-preference   {"fon":"rgb(20, 24, 31)","tekst":"rgb(232, 236, 243)","buton":"rgb(138, 164, 255)","animacia":"puls"}
dark reduce          {"fon":"rgb(20, 24, 31)","tekst":"rgb(232, 236, 243)","buton":"rgb(138, 164, 255)","animacia":"none"}
```

Забележи три неща: в тъмната тема фонът, текстът и бутонът са сменени без нито едно ново правило за елементите; при `reduce` анимацията е `none`; а прехода на бутона остава, докато не го изключиш изрично. След добавяне на блока `@media (prefers-reduced-motion: reduce) { .btn { transition: none; } }` изчислената продължителност на прехода стана:

```
0s
```

Ръчната тема също работи. Добавих правилото `:root[data-theme="dark"]` със същите стойности и при светла система смених атрибута, като прочетох цвета на фона преди и след:

```
rgb(255, 255, 255)
rgb(20, 24, 31)
```

## Чести грешки
- **Променливи по цвят, а не по роля** – `--blue` в тъмна тема не е синьо. Ползвай `--accent`.
- **Една и съща стойност за акцент в двете теми** – контрастът се разваля. Провери и двете.
- **Забравен `color-scheme`** – полетата и скролбаровете остават светли на тъмен фон.
- **`transition: all`** – анимира неочаквани свойства и е по-скъпо. Изброй конкретни.
- **Преход на `width`, `height` или `top`** – налага ново подреждане. Предпочитай `transform` и `opacity`.
- **Прехода е записан само в `:hover`** – при връщането връщането е рязко. Слагай го в изходното състояние.
- **Безкрайна анимация без `prefers-reduced-motion`** – вреди на част от потребителите. Включвай я само при `no-preference`.
- **Дълги анимации (над секунда) на често ползвани бутони** – сайтът изглежда муден. За малки състояния стигат 150–300 милисекунди.

## Упражнение

Добави на личната си страница тъмна тема и плавен преход.

1. Събери повтарящите се цветове в променливи по роли в `:root`.
2. Добави `@media (prefers-color-scheme: dark)` с нови стойности. Измери контраста на текста и на бутона в двете теми.
3. Добави `transition` на бутоните и `:hover`/`:focus-visible` стил.
4. По желание: една анимация с `@keyframes`, включена само при `no-preference`.
5. Емулирай тъмна тема и намалено движение в инструментите на браузъра и провери, че всичко работи.

Критерии за самопроверка:
- Никой цвят не е написан повече от веднъж извън `:root`.
- Смяната на темата не изисква ново правило за нито един елемент.
- Контрастът е поне 4,5:1 за текста в двете теми.
- Бутонът реагира плавно (около 150–300 ms) както с мишка, така и с `Tab`.
- При `reduce` няма безкрайно или голямо движение.

## Бърза справка

| Задача | Запис |
|---|---|
| Декларация на променлива | `:root { --accent: #0b4fb3; }` |
| Ползване | `color: var(--accent);` или `var(--accent, blue)` |
| Локална промяна | `.card { --accent: #b3261e; }` |
| Тъмна тема по системата | `@media (prefers-color-scheme: dark) { :root { … } }` |
| Ръчна тема | `:root[data-theme="dark"] { … }` |
| Преход | `transition: transform .25s ease;` |
| Движение без пренареждане | `transform`, `opacity` |
| Анимация | `@keyframes име { … }` + `animation: име 1s infinite;` |
| Намалено движение | `@media (prefers-reduced-motion: reduce) { … }` |

## Обобщение
CSS променливите събират стойностите на едно място и позволяват да смениш цялата тема, като презапишеш няколко стойности. Тъмната тема е нов набор променливи, активиран от `prefers-color-scheme` или от атрибут. Преходите правят промяната плавна, а `@keyframes` дават самостоятелна анимация. Движението ползваш пестеливо, предпочиташ `transform` и `opacity` и го изключваш за хората, които са поискали по-малко анимация.
