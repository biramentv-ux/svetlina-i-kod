## Какво ще научиш
- три начина да запишеш функция и кога да ползваш стрелкова функция
- какво са параметри по подразбиране, rest параметри и функции като стойности

## Функции
Функцията е именувана част от код, която приема данни, върши работа и (по желание) връща резултат. В JavaScript има няколко записа:

```js
function add(a, b) { return a + b; }
const mul = function (a, b) { return a * b; };
const sq = (x) => x * x;
const greet = (name = "гост", ...rest) => `Здравей, ${name}! (${rest.length} допълнителни)`;
console.log(add(2, 3), mul(2, 3), sq(5), greet(), greet("Иво", 1, 2));
```

```
5 6 25 Здравей, гост! (0 допълнителни) Здравей, Иво! (2 допълнителни)
```

Първият запис е декларация, вторият е функционален израз, а третият – стрелкова функция (arrow function). Стрелковата е най-кратка: ако тялото е един израз, `return` и къдравите скоби се пропускат. Параметър със `= "гост"` получава стойност по подразбиране, а `...rest` събира всички останали аргументи в масив.

JavaScript не проверява броя на аргументите. Липсващият става `undefined`, а излишните просто се игнорират:

```js
console.log(add(1), add(1, 2, 3), (function () {})());
```

```
NaN 3 undefined
```

Функция без `return` връща `undefined`. Декларациите се „вдигат“ и могат да се извикат преди реда си, докато `var` и `const` не могат:

```js
console.log(hoisted(), typeof notYet);
function hoisted() { return "вдигната"; }
var notYet = () => 1;
```

```
вдигната undefined
```

Затова пиши функциите си над мястото, където ги ползваш, или като `const`, и не разчитай на вдигането.

### Функциите са стойности
Функцията може да се запише в променлива, да се подаде на друга функция или да се върне като резултат. Подадена функция се нарича функция за обратно извикване (callback):

```js
const apply = (f, x) => f(f(x));
console.log(apply(sq, 3));
```

```
81
```

Функция, върната от друга, „помни“ променливите от мястото, където е създадена. Това се нарича затваряне (closure) и е основата за много шаблони:

```js
function counter() { let c = 0; return () => ++c; }
const c1 = counter(); c1(); c1();
console.log(c1(), counter()());
```

```
3 1
```

Всяко извикване на `counter()` създава собствено `c`, затова втората функция започва от 1.

## Масиви
Масивът е подреден списък, номериран от 0. Най-честите операции:

```js
const nums = [4, 8, 15, 16, 23, 42];
console.log(nums.length, nums[0], nums.at(-1), nums.indexOf(15), nums.includes(99));
nums.push(50);
console.log(nums.pop(), nums);
```

```
6 4 42 2 false
50 [ 4, 8, 15, 16, 23, 42 ]
```

`at(-1)` връща последния елемент, `push` добавя в края, `pop` маха последния и го връща.

### map, filter, reduce
Това са трите най-важни метода. Те не променят оригиналния масив, а връщат нов резултат:

```js
console.log(nums.map(x => x * 2), nums.filter(x => x % 2 === 0), nums.reduce((s, x) => s + x, 0));
```

```
[ 8, 16, 30, 32, 46, 84 ] [ 4, 8, 16, 42 ] 108
```

- `map` превръща всеки елемент в друг и връща масив със същата дължина.
- `filter` оставя само елементите, за които функцията върне истина.
- `reduce` сгъва масива в една стойност. Вторият аргумент (`0`) е началната стойност на натрупването.

За търсене има `find`, `findIndex`, `some` и `every`:

```js
console.log(nums.find(x => x > 15), nums.findIndex(x => x > 15), nums.some(x => x > 40), nums.every(x => x > 4));
```

```
16 3 true false
```

### Сортиране: капанът
`sort` без аргумент подрежда елементите като низове, затова числата излизат объркани. Освен това той променя самия масив:

```js
console.log([...nums].sort(), [...nums].sort((a, b) => a - b), nums);
console.log([10, 9, 1].sort(), [3, 1, 2].toSorted((a, b) => a - b));
```

```
[ 15, 16, 23, 4, 42, 8 ] [ 4, 8, 15, 16, 23, 42 ] [ 4, 8, 15, 16, 23, 42 ]
[ 1, 10, 9 ] [ 1, 2, 3 ]
```

Подавай функция за сравнение `(a, b) => a - b`. Копирай масива с `[...nums]`, ако не искаш да го променяш; `toSorted` в Node 22 и в актуалните браузъри прави това вместо теб.

| Метод | Променя ли оригинала | Връща |
| --- | --- | --- |
| `map`, `filter`, `slice`, `concat` | не | нов масив |
| `reduce` | не | една стойност |
| `find`, `some`, `every`, `includes` | не | елемент или true/false |
| `push`, `pop`, `shift`, `unshift`, `splice` | да | различно |
| `sort`, `reverse` | да | същия масив |
| `toSorted`, `toReversed` | не | нов масив |

## Обекти
Обектът свързва имена със стойности. Той е естественият начин да опишеш нещо с няколко свойства, а записът му е почти същият като JSON, който ще виждаш при работа с мрежата.

```js
const person = { name: "Елена", age: 30, skills: ["JS", "CSS"], greet() { return `Аз съм ${this.name}`; } };
console.log(person.name, person["age"], person.greet(), person.missing);
person.city = "Варна"; delete person.age;
console.log(Object.keys(person), Object.values({ a: 1, b: 2 }), Object.entries({ a: 1, b: 2 }));
```

```
Елена 30 Аз съм Елена undefined
[ 'name', 'skills', 'greet', 'city' ] [ 1, 2 ] [ [ 'a', 1 ], [ 'b', 2 ] ]
```

Достъпът с точка е за известни имена, а със скоби – когато името е в променлива. Липсващо свойство дава `undefined`, не грешка. Функцията в обект се нарича метод, а `this` вътре сочи към обекта, от който я извикваш. Стрелковите функции нямат собствено `this`, затова за методи в обект пиши обикновен запис.

### Деструктуриране и spread
Деструктурирането изважда части от обект или масив наведнъж, като може да задава стойности по подразбиране:

```js
const { name, skills: [first, ...others], city = "—", zip = "няма" } = person;
console.log(name, first, others, city, zip);
```

```
Елена JS [ 'CSS' ] Варна няма
```

Подобно се прави и в параметрите: `({ name }) => name` взима само името. Операторът spread `...` разгръща масив или обект и се ползва за копиране и обединяване: `{ ...a, n: 3 }`, `[...nums, 99]`.

### Референции: копира ли се наистина?
Обектите и масивите се присвояват по референция. Две имена може да сочат към един и същ обект:

```js
const a = { n: 1, tags: ["x"] };
const alias = a; alias.n = 2; console.log(a.n);
const copy = { ...a, n: 3 }; copy.tags.push("y"); console.log(a, copy);
const deep = structuredClone(a); deep.tags.push("z"); console.log(a.tags, deep.tags);
```

```
2
{ n: 2, tags: [ 'x', 'y' ] } { n: 3, tags: [ 'x', 'y' ] }
[ 'x', 'y' ] [ 'x', 'y', 'z' ]
```

`alias` не е копие, а второ име. Spread прави плитко копие: `n` е ново, но `tags` още е общият масив. За пълно копие ползвай `structuredClone`. Същото важи и за `const`: константният масив може да расте с `push`, само не може да бъде заменен с друг (`Assignment to constant variable.`).

Същата причина обяснява защо функция, която получава обект, може да го промени отвътре. В пример `f = (x) => { x.n = 99; x = null; }` след извикване `o` е `{ n: 99 }` – свойството е променено, а присвояването `x = null` не засяга `o`.

## Пример от практиката
Да кажем, че водиш списък с оценки на ученици от курс:

```js
const students = [{ name: "Ана", grade: 5.5 }, { name: "Борис", grade: 4 }, { name: "Вера", grade: 6 }];
const best = students.reduce((b, s) => s.grade > b.grade ? s : b);
console.log(best, students.map(({ name }) => name));
```

```
{ name: 'Вера', grade: 6 } [ 'Ана', 'Борис', 'Вера' ]
```

`reduce` без начална стойност започва с първия елемент и държи „най-добрия до момента“. `map` с деструктуриране извлича имената. Същата форма на данни (масив от обекти) ще ползваш при показване на списъци в страницата и при отговори от мрежата.

## Чести грешки
- **`sort()` на числа без функция** – подрежда ги като текст. Подай `(a, b) => a - b`.
- **`reduce` на празен масив без начална стойност** – хвърля грешка. Подай начална стойност.
- **Очакване `const` да прави обекта неизменяем** – `const` пази името, не съдържанието.
- **Плитко копие вместо дълбоко** – вложените обекти остават общи. Ползвай `structuredClone`.
- **Стрелкова функция за метод със `this`** – няма собствено `this`. Пиши `greet() { ... }`.
- **`map`, когато резултатът не се ползва** – за страничен ефект ползвай `for...of`.
- **Забравен `return`** при тяло в къдрави скоби – функцията връща `undefined`.

## Упражнение
Дадени са оценки: `const marks = [5.5, 4, 6, 3.5, 5, 2.5, 6];`. Напиши функция `stats(marks)`, която връща обект със средна, най-висока и най-ниска оценка и брой слаби оценки (под 3). Изведи резултата с `console.log`.

Критерии за проверка:
- средната е `4.64` при закръгляне до два знака с `toFixed(2)`, най-високата е `6`, най-ниската е `2.5`, слабите са `1`
- ползваш `reduce` (или `Math.max`/`Math.min` със spread) и `filter`
- функцията не променя масива `marks`
- връща обект и използваш деструктуриране при извикването: `const { average, best } = stats(marks);`

## Бърза справка
| Задача | Код |
| --- | --- |
| Стрелкова функция | `const f = (x) => x * 2;` |
| Стойност по подразбиране | `(x = 0) => ...` |
| Всички останали аргументи | `(...args) => ...` |
| Нов масив с промяна | `arr.map(fn)` |
| Само някои | `arr.filter(fn)` |
| Сума | `arr.reduce((s, x) => s + x, 0)` |
| Копие на масив/обект | `[...arr]`, `{ ...obj }` |
| Дълбоко копие | `structuredClone(obj)` |
| Деструктуриране | `const { a, b } = obj;` |

## Обобщение
Функциите са стойности и могат да се подават като аргументи. Масивите се обработват най-четимо с `map`, `filter` и `reduce`, които връщат нови стойности. Обектите описват единица данни, а деструктурирането и spread ги разопаковат и копират, но само на едно ниво. Помни, че присвояването на обект създава второ име, а не копие.
