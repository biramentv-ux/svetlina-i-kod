> **Цел на урока:** да пишеш първите си програми на JavaScript: да пазиш стойности в променливи, да познаваш основните типове и да караш кода да взима решения с условия.

## Какво ще научиш
- как се обявяват променливи с `const` и `let` и защо днес не се пише `var`
- кои са основните типове данни и как да ги проверяваш с `typeof`
- разликата между `==` и `===` и кои стойности се смятат за „лъжливи“
- как работят `if`, `else`, `switch`, тернарният оператор и циклите `for` и `while`
- как да ползваш конзолата като бележник за експерименти

## Къде се пише JavaScript
JavaScript е езикът, който браузърът изпълнява вътре в страницата. Днес същият език върви и извън браузъра, в Node.js. В този урок кодът не работи с елементи от страницата, затова можеш да го пускаш по два начина: в конзолата на браузъра (в повечето браузъри се отваря с F12, в раздела „Console“) или във файл, който пускаш с `node app.js`. Примерите тук са изпълнени с Node 22, а изходът е копиран от реалното изпълнение.

Конзолата е твоят бележник. `console.log(...)` приема колкото искаш стойности и ги пише на един ред, разделени с интервал. Има и `console.warn`, `console.error` и `console.table` за масиви от обекти.

Ако искаш по-общ поглед върху програмирането, пътеката `programirane-ot-nulata` обяснява същите идеи без връзка с уеб.

## Променливи: const и let
Променливата е име, зад което стои стойност. Съвременният JavaScript има две ключови думи за това.

```js
const school = "Светлина и код";
let students = 12;
students = students + 1;
console.log(school, students);
```

```
Светлина и код 13
```

`const` значи, че името не може да бъде насочено към друга стойност. `let` позволява преприсвояване. Опитът да промениш константа дава грешка, която можеш да прочетеш:

```
TypeError: Assignment to constant variable.
```

Правилото за начинаещи е просто: започвай с `const` и сменяй на `let` само когато наистина трябва да промениш стойността. Така кодът ти казва кое се променя и кое не. Старата форма `var` има странности (видима е извън блока, в който е обявена, и се „вдига“), затова в нов код не се използва.

`let` и `const` важат само в блока `{ ... }`, в който са обявени, и не могат да се четат преди реда си. Ако опиташ, получаваш:

```
ReferenceError: Cannot access 'late' before initialization
```

Имената са чувствителни към регистъра (`score` и `Score` са различни), започват с буква, `_` или `$` и по конвенция се пишат в camelCase: `studentCount`. Може да ползваш и кирилица, но на практика всички пишат имената на английски, а текстовете за потребителя на български.

## Типове данни
Стойностите в JavaScript имат тип. Операторът `typeof` го показва:

```js
console.log(typeof 42, typeof 3.14, typeof "здравей", typeof true,
  typeof undefined, typeof null, typeof 10n, typeof [], typeof {}, typeof (() => 1));
```

```
number number string boolean undefined object bigint object object function
```

| Тип | Пример | Бележка |
| --- | --- | --- |
| number | `42`, `3.14` | и цели, и дробни числа са един тип |
| string | `"текст"`, `'текст'` | поредица от знаци |
| boolean | `true`, `false` | логическа стойност |
| undefined | `undefined` | променлива без стойност |
| null | `null` | умишлено „нищо“ |
| bigint | `10n` | много големи цели числа |
| object | `{}`, `[]` | обекти и масиви (масивът също е обект) |

Две неща изненадват всеки. Първо, `typeof null` връща `"object"` – това е стара грешка в езика, която никога не е поправена, за да не се счупят съществуващите сайтове. Второ, числата са двоични дроби с плаваща запетая, затова дробните сметки не винаги са точни:

```js
console.log(0.1 + 0.2, 0.1 + 0.2 === 0.3);
console.log(Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON);
```

```
0.30000000000000004 false
true
```

Така че дробни числа не се сравняват с `===`, а се проверява дали разликата е достатъчно малка. Цели числа са безопасни до `Number.MAX_SAFE_INTEGER`, което е `9007199254740991`; над него ползвай `bigint`.

### Низове и шаблони
Низовете могат да са в двойни, единични или обратни кавички. Обратните кавички образуват шаблонен низ (template literal), в който вмъкваш израз с `${...}`:

```js
const name = "Мария", n = 3;
console.log(`Здравей, ${name}! Имаш ${n} съобщения, ${n * 2} са след ${(1.5).toFixed(2)} ч.`);
console.log("Привет".length, "Привет".toUpperCase(), "а,б,в".split(","), "  тест ".trim());
```

```
Здравей, Мария! Имаш 3 съобщения, 6 са след 1.50 ч.
6 ПРИВЕТ [ 'а', 'б', 'в' ] тест
```

### Преобразуване на числа
Текстът от формите винаги е низ, затова често ще превръщаш в число:

```js
console.log("abc" * 2, Number("12"), Number(""), Number("12px"), parseInt("12px"), parseFloat("3.5kg"));
```

```
NaN 12 0 NaN 12 3.5
```

`NaN` (not a number) е стойността, която получаваш от невъзможна сметка. Любопитно е, че `NaN === NaN` е `false`, затова се проверява с `Number.isNaN(x)`.

## Оператори и сравнение
Аритметичните оператори са познатите `+ - * /`, плюс остатък `%` и степен `**`:

```js
console.log(10 / 3, 10 % 3, 2 ** 10, Math.floor(10 / 3), -7 % 3);
```

```
3.3333333333333335 1 1024 3 -1
```

Обърни внимание на `-7 % 3`: остатъкът взема знака на делимото. Операторът `+` е и за събиране, и за слепване на низове, което води до класическа грешка:

```js
console.log("5" + 3, "5" - 3, "5" * "2", true + 1);
```

```
53 2 10 2
```

### == или ===
Операторът `==` преобразува типовете, преди да сравни, а `===` сравнява стойност и тип. Първият е източник на трудни за намиране грешки:

```js
console.log(1 == "1", 1 === "1", null == undefined, null === undefined, 0 == "", 0 === "");
```

```
true false true false true false
```

Винаги ползвай `===` и `!==`. Единственото разумно изключение е `x == null`, което хваща едновременно `null` и `undefined`, но и там е по-ясно да си го напишеш изрично.

### Истинни и лъжливи стойности
В условие всяка стойност се превръща в `true` или `false`. Лъжливи (falsy) са точно осем стойности: `false`, `0`, `-0`, `0n`, `""` (празен низ), `null`, `undefined` и `NaN`. Всичко останало е истинно, включително `"0"`, `[]` и `{}`. Сигурно е да го провериш с `Boolean(стойност)`. Ето изходът на цикъл, който подава поредица от стойности:

```
0 -> false
"" -> false
null -> false
undefined -> false
null -> false
false -> false
"0" -> true
[] -> true
{} -> true
-1 -> true
```

Петият ред се чете „null“, защото `NaN` не може да се запише в JSON и `JSON.stringify` го превръща в `null`; самата стойност е `NaN` и пак е `false`.

Два полезни оператора за стойности по подразбиране:

```js
let user;
console.log(user ?? "гост", 0 || "по подразбиране", 0 ?? "по подразбиране");
const cfg = { theme: { color: "тъмна" } };
console.log(cfg.theme?.color, cfg.lang?.code, cfg.lang?.code ?? "bg");
```

```
гост по подразбиране 0
тъмна undefined bg
```

`??` подменя само `null` и `undefined`, докато `||` подменя всяка лъжлива стойност, включително законното `0`. Опционалното свързване `?.` спира веригата и връща `undefined`, вместо да хвърли грешка, когато по пътя липсва обект.

## Условия и цикли
Най-простото решение е `if`:

```js
function grade(m) {
  if (m >= 5.5) return "отличен";
  else if (m >= 4.5) return "много добър";
  else if (m >= 3.5) return "добър";
  else if (m >= 3) return "среден";
  return "слаб";
}
console.log([6, 5, 4, 3, 2].map(grade));
```

```
[ 'отличен', 'много добър', 'добър', 'среден', 'слаб' ]
```

За избор между точни стойности е удобен `switch`. Всеки `case` трябва да завършва с `return` или `break`, иначе изпълнението „пада“ в следващия. Две съседни стойности могат да делят един резултат:

```js
function day(d) {
  switch (d) {
    case 6: case 7: return "почивен";
    case 1: return "понеделник";
    default: return "делничен";
  }
}
console.log(day(1), day(7), day(3));
```

```
понеделник почивен делничен
```

За кратък избор на стойност има тернарен оператор: `age >= 18 ? "пълнолетен" : "непълнолетен"`. За повторение ползвай `for` и `while`:

```js
let i = 0;
while (i < 3) { console.log("i =", i); i++; }
for (let k = 1; k <= 3; k++) console.log(k * k);
```

```
i = 0
i = 1
i = 2
1
4
9
```

Внимавай условието на цикъла някога да стане невярно, иначе програмата зациклява.

## Стъпка по стъпка
1. Отвори конзолата на браузъра или създай файл `app.js`.
2. Обяви `const` за всичко, което няма да се променя, и `let` за броячи.
3. Изведи резултатите с `console.log`, като подаваш повече от една стойност.
4. Провери типа с `typeof`, когато резултатът те учудва.
5. Сравнявай само с `===` и записвай условията с ясни имена.
6. При грешка прочети съобщението докрай, преди да променяш нещо.

## Пример от практиката
Да кажем, че правиш малка страница за училищен клуб и искаш да изведеш поздрав според часа. Часът идва от `new Date().getHours()`, а при липсващо име се показва „гост“:

```js
function greeting(hour, name) {
  const who = name ?? "гост";
  if (hour < 12) return `Добро утро, ${who}!`;
  if (hour < 18) return `Добър ден, ${who}!`;
  return `Добър вечер, ${who}!`;
}
```

Така `greeting(9)` връща „Добро утро, гост!“, а `greeting(15, "Мария")` – „Добър ден, Мария!“. Забележи едно ограничение: празният низ не е `null`, затова `greeting(21, "")` дава „Добър вечер, !“. Ако искаш празното име също да става „гост“, замени `??` с `||` – тук това е допустимо, защото празно име няма смисъл. Функцията е малка, тества се с три извиквания и не зависи от страницата, затова можеш да я използваш по-късно в DOM примерите.

## Чести грешки
- **Ползване на `==`** – превръща типовете скришом и дава изненади като `0 == ""`. Пиши `===`.
- **`const` за стойност, която ще се променя** – получаваш `TypeError`. Смени с `let`.
- **Сравняване на дробни числа с `===`** – `0.1 + 0.2` не е `0.3`. Сравнявай с допустима разлика или работи в цели единици (например стотинки).
- **Слепване вместо събиране** – `"5" + 3` дава `"53"`. Преобразувай с `Number()`.
- **Забравен `break` в `switch`** – изпълнението продължава в следващия `case`.
- **`||` за стойности по подразбиране при число** – `0` се губи. Ползвай `??`.
- **Очакване `typeof null` да е `"null"`** – проверявай с `x === null`.

## Упражнение
Напиши функция `isLeap(year)`, която връща `true` за високосна година. Правило: годината се дели на 4, но не и на 100, освен ако не се дели на 400. След това извикай функцията в цикъл за годините 1900, 2000, 2023, 2024 и 2100 и изведи резултата с `console.log`.

Критерии за проверка:
- функцията връща `false` за 1900, `true` за 2000, `false` за 2023, `true` за 2024 и `false` за 2100
- ползваш `const` или `let` по смисъл и само `===`
- няма излишен `if`, който връща `true` или `false` – условието може да е един израз
- реши как да се държи функцията при низ като `"2024"`: операторът `%` ще го преобразува мълчаливо, затова реши дали да го приемеш, или да го преобразуваш предварително с `Number()`

## Бърза справка
| Задача | Код |
| --- | --- |
| Константа | `const x = 5;` |
| Променлива | `let x = 5;` |
| Тип | `typeof x` |
| Низ в число | `Number("12")` |
| Проверка за NaN | `Number.isNaN(x)` |
| Стойност по подразбиране | `x ?? "н/д"` |
| Безопасен достъп | `obj?.a?.b` |
| Шаблон | `` `Здравей, ${name}` `` |
| Тернарен избор | `a ? b : c` |

## Обобщение
Променливите се обявяват с `const` по подразбиране и с `let`, когато стойността се променя. Основните типове са число, низ, булева стойност, `undefined`, `null` и `bigint`, а `typeof` ги разпознава с известни странности. Сравнявай с `===`, помни кои стойности са лъжливи и ползвай `??` за стойности по подразбиране. Условията `if` и `switch` избират път, а циклите повтарят действия, докато условието е вярно.
