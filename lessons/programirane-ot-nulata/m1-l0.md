## Какво е стойност и какво е тип
Представи си, че в кухнята имаш буркани с етикети: „захар“, „брашно“, „сол“. Съдържанието на буркана е **стойност**, а надписът върху него е **име**. В програмирането е същото: числото `25`, думата „Мария“ и отговорът „да/не“ са стойности, а ние им слагаме имена, за да ги намираме по-късно.

Всяка стойност има **тип (type)** – вид, който казва какво може да се прави с нея. С числа можеш да събираш, с думи – да ги слепваш и да ги правиш с главни букви. Не можеш да „умножиш“ „Мария“ по „Иван“. Типът е договорът между теб и компютъра за това какво е стойността.

Python ти показва типа на всяка стойност с вградената функция `type()`. Ето пет стойности, по една от всеки основен тип:

```python
age = 25
price = 3.5
name = "Мария"
is_student = True
nothing = None
for v in (age, price, name, is_student, nothing):
    print(repr(v), type(v))
```

Изход:

```
25 <class 'int'>
3.5 <class 'float'>
'Мария' <class 'str'>
True <class 'bool'>
None <class 'NoneType'>
```

Функцията `repr()` показва стойността така, както би я написал в кода – затова текстът е в кавички и се вижда, че `'Мария'` е низ, а не име. Редът с `for` засега чети като „за всяка стойност от списъка направи следното“; той е тема на следващия урок.

## Променливата е етикет
Реда `age = 25` четеш така: „нека името `age` сочи към стойността 25“. Знакът `=` не е равенство от математиката, а **присвояване (assignment)**: взема стойността отдясно и закача отляво име към нея.

Често казват, че променливата е „кутия със стойност“. Образът е удобен, но подвежда. По-точно е да мислиш за етикет, който можеш да преместиш към друга стойност или да закачиш втори етикет към същата. Ето малък опит:

```python
a = 5
b = a
a = a + 1
print(a, b)
a += 10
print(a)
x, y = 1, 2
x, y = y, x
print(x, y)
```

```
6 5
16
2 1
```

Какво се случи. `b = a` закачи второто име към числото 5. После `a = a + 1` пресметна 6 и премести етикета `a` към него, а `b` остана при 5. Записът `a += 10` е кратък за `a = a + 10`. А редът `x, y = y, x` разменя две стойности наведнъж – нещо, което в много други езици иска трета помощна променлива.

### Как да именуваш променливите
Правилата на Python са прости. Името започва с буква или `_`, съдържа букви, цифри и `_`, и не е запазена дума като `if` или `for`. Главните и малките букви се различават: `age` и `Age` са две различни имена.

Правилата на добрия стил са по-важни от правилата на езика:
- Пиши имена на английски с малки букви и долна черта: `total_price`, `user_name`. Така се пише в целия Python свят.
- Давай имена, които казват какво има вътре: `months` е по-добро от `m` и от `x1`.
- Не използвай имената на вградени функции като `print`, `type`, `input` и `list` за променливи, защото ги „затъмняваш“ и после функцията спира да работи.

Текстовете и коментарите могат да са на български – Python 3 работи с Unicode.

## Петте основни типа

| Тип | Какво съдържа | Пример |
|---|---|---|
| `int` | цяло число | `7`, `-3`, `1000000` |
| `float` | число с десетична част | `3.5`, `0.1`, `2.0` |
| `str` | текст (низ, string) | `"Варна"`, `'Здравей'` |
| `bool` | истина или лъжа | `True`, `False` |
| `NoneType` | „нищо“, липса на стойност | `None` |

Десетичният знак в Python е точка, не запетая: `3.5`, а не `3,5`.

### Числа и аритметика
Операторите са познати, но два от тях са нови за повечето хора:

```python
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(10 / 5)
print(type(10 / 5))
print(-7 // 2, -7 % 2)
```

```
9 5 14
3.5
3
1
1024
2.0
<class 'float'>
-4 1
```

- `/` е обикновеното деление и **винаги** връща `float`, дори когато се дели точно: `10 / 5` дава `2.0`.
- `//` е целочислено деление: колко пъти се събира делителят, без остатъка. `7 // 2` е 3.
- `%` връща остатъка: `7 % 2` е 1. Чете се „по модул“ и е чудесен за въпроса „четно ли е числото?“ (`n % 2 == 0`).
- `**` е степенуване.

Внимавай с отрицателните числа: `-7 // 2` е `-4`, защото целочисленото деление закръглява надолу, към по-малкото число, а не към нулата.

### Коварството на десетичните числа
Компютърът пази `float` в двоична форма и много десетични дроби не могат да се запишат в нея точно. Затова се случва това:

```python
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
```

```
0.30000000000000004
0.3
```

Това не е грешка на Python, а свойство на двоичните дроби, което имат почти всички езици. Практическият извод: не сравнявай десетични числа с `==` и закръглявай с `round()` или при печатане. За пари в истински програми се използват други средства, но засега ти стига да знаеш, че това съществува.

### Низове
Низът е текст между кавички – единични или двойни, няма разлика. Можеш да ги слепваш с `+`, да ги повтаряш с `*` и да питаш за дължината им с `len()`:

```python
name = "Иван"
city = "Варна"
print("Здравей, " + name + "!")
print(f"{name} живее във {city}.")
print(len(name), name.upper(), name[0])
print("ха" * 3)
price = 3.456
print(f"Цена: {price:.2f} лв.")
print(len("Привет"))
```

```
Здравей, Иван!
Иван живее във Варна.
4 ИВАН И
хахаха
Цена: 3.46 лв.
6
```

Най-удобният начин да вмъкнеш стойности в текст е **f-низът**: поставяш `f` пред кавичките и пишеш имената между фигурни скоби. Вътре в скобите можеш да добавиш формат: `{price:.2f}` означава „число с две цифри след точката“. Индексът `name[0]` взема първия символ – бройката в Python започва от нула, за което ще говорим подробно, когато стигнем до списъците.

Забележи и `len("Привет")` = 6: Python 3 брои символи, а не байтове, така че кирилицата не е проблем.

### Логически стойности и сравнения
Типът `bool` има само две стойности: `True` и `False`. Получаваш ги от сравненията:

```python
print(5 > 3, 5 == 5.0, "а" == "А", 3 != 4)
print(True and False, True or False, not True)
x = None
print(x is None)
print(bool(0), bool(""), bool("0"), bool(42))
```

```
True True False True
False True False
True
False False True True
```

Сравнителните оператори са `==` (равно), `!=` (различно), `<`, `>`, `<=`, `>=`. Двойното `==` пита „равни ли са?“, а единичното `=` присвоява – най-честата грешка на начинаещите е да ги бъркат. Логическите оператори са `and`, `or` и `not`.

Две неща си струва да запомниш от изхода. Първо, малката и главната буква са различни символи: `"а" == "А"` е `False`. Второ, всяка стойност има „истинност“: `0`, празният низ и `None` се държат като `False`, а почти всичко останало – като `True`. Затова `bool("0")` е `True` – това е непразен низ, а не числото нула.

### None
`None` е специалната стойност „тук няма нищо“. Ползваме я, когато искаме да кажем „още няма отговор“ или „функцията не върна нищо“. Проверява се с `is None`, не с `==`.

## Преобразуване между типове
Типовете често трябва да се сменят. Функциите-преобразуватели носят имената на типовете: `int()`, `float()`, `str()`, `bool()`.

```python
print(int("42") + 1, float("3.5") * 2, str(7) + "7")
print(int(3.9), int(-3.9))
```

```
43 7.0 77
```

`str(7) + "7"` дава `"77"` – слепване на низове, не събиране. А `int(3.9)` дава 3 и `int(-3.9)` дава -3: `int()` просто отрязва десетичната част към нулата, не закръглява. За закръгляване ползвай `round()`.

Преобразуването може и да се провали – и това е нормално. Видяхме го с `int("abc")` по-долу, в раздела за грешките.

## Стъпка по стъпка: първата ти програма с вход
Целта е програма, която пита за години и казва колко месеца са това.

1. Създай папка за курса и в нея файл `months.py` в редактора си.
2. Добави реда, който пита и чете отговора:
   `years = int(input("На колко години си? "))`
   Функцията `input()` показва въпроса, чака да напишеш нещо и натиснеш Enter, и връща написаното като **низ**. Затова го обвиваме в `int()`.
3. Пресметни резултата: `months = years * 12`.
4. Отпечатай го: `print(f"Това са {months} месеца.")`.
5. Пусни програмата от терминала с `python3 months.py` (в Windows често е `python months.py` или `py months.py`, в зависимост от инсталацията).

Целият файл:

```python
years = int(input("На колко години си? "))
months = years * 12
print(f"Това са {months} месеца.")
```

За да получа точния изход тук, подадох отговора през канал: `echo 25 | python3 months.py`. Видях:

```
На колко години си? Това са 300 месеца.
```

Двата реда са слепени, защото отговорът 25 дойде през канал, а не от клавиатурата, така че няма Enter на екрана. Когато пишеш сам, ще видиш `25` след въпроса и резултатът ще е на нов ред.

## Как да четеш съобщенията за грешки
Грешките са ежедневие, а не провал. Python ти казва какво е станало, стига да умееш да четеш. Най-важният ред е **последният**: той назовава вида на грешката и причината. Над него са файлът и редът, където се е случило.

Ето трите грешки, които ще срещаш най-често (показвам само последния ред):

```
TypeError: can only concatenate str (not "int") to str
```
`"5" + 3` – опит да слепиш текст с число. Python не познава какво искаш: „53“ или 8? Реши ти: `"5" + str(3)` или `int("5") + 3`.

```
ValueError: invalid literal for int() with base 10: 'abc'
```
Типът е правилен (низ), но стойността не може да стане число. Същото се случва, ако в програмата с месеците въведеш `12.5` или текст.

```
NameError: name 'totl' is not defined
```
Използвал си име, което не съществува – почти винаги правописна грешка (`totl` вместо `total`).

## Пример от практиката
Да кажем, че организираш лична игра и искаш програма, която пресмята колко струва билетите за компания. Цената на билет е 7,5 лв., а ти въвеждаш броя хора:

```python
ticket = 7.5
people = int(input("Колко души сте? "))
total = ticket * people
print(f"Общо: {total:.2f} лв., по {total / people:.2f} лв. на човек.")
```

Тук виждаш всичко от урока: `float` и `int` в едно умножение (резултатът е `float`), преобразуване на входа, f-низ с формат. С 4 души пуснах програмата и получих `Общо: 30.00 лв., по 7.50 лв. на човек.` С 0 души тя спира с `ZeroDivisionError: float division by zero`, защото делиш на нула. Как да я предпазиш, ще научиш в следващия урок с `if`.

## Чести грешки
- **Забравено преобразуване на `input()`** – `input()` винаги връща низ, затова `input() + 1` дава `TypeError`. Обвий го в `int()` или `float()`.
- **`=` вместо `==`** – единичното присвоява, двойното сравнява. Смесването им е класика.
- **Запетая вместо точка** – `3,5` не е число с десетична част; пиши `3.5`.
- **Правописна грешка в име** – Python различава `Total` от `total`. Копирай имената или ползвай автоматичното допълване на редактора.
- **Очакване `/` да връща цяло число** – дори `10 / 5` е `2.0`. Ако ти трябва `int`, използвай `//`.
- **Име на променлива като на вградена функция** – ако напишеш `list = [1, 2]`, после `list(...)` вече не работи. Избирай други имена.

## Упражнение
Напиши програма `profile.py`, която:
1. пита за име и за възраст;
2. пресмята на колко месеца е човекът и в коя година ще навърши 100 (използвай текущата година, написана като число в кода, например `2026`);
3. отпечатва два реда с f-низове, например „Здравей, Мария!“ и „На 25 години си: това са 300 месеца.“;

Провери сам:
- програмата работи с възраст, въведена като число;
- няма нито един ред, в който слепваш низ с число без преобразуване;
- имената на променливите са английски, описателни и с малки букви;
- когато нарочно въведеш „abc“ за възраст, разбираш по последния ред на грешката какво се е случило и защо.

Бонус: добави ред, който пресмята колко години остават до 100 и ги печата с `{value:.1f}`.

## Бърза справка

| Задача | Запис |
|---|---|
| Присвояване | `x = 5` |
| Събиране на място | `x += 1` |
| Деление / целочислено / остатък | `/`, `//`, `%` |
| Степен | `2 ** 10` |
| Тип на стойност | `type(x)` |
| Преобразуване | `int()`, `float()`, `str()`, `bool()` |
| Четене на вход | `input("въпрос ")` (връща `str`) |
| Печат с вмъкване | `print(f"{name}: {x:.2f}")` |
| Дължина на низ | `len(s)` |
| Сравнения | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| Логика | `and`, `or`, `not` |
| Проверка за „нищо“ | `x is None` |

Връзка с другите пътеки: когато по-нататък изпращаш заявки към ИИ модел, ще предаваш текст като низове и ще получаваш числа и отговори, които трябва да преобразуваш – точно с тези функции. А в курса по reverse engineering ще видиш, че типовете „изчезват“ в машинния код: там остават само байтове и инструкции.

## Обобщение
Всяка стойност в Python има тип, а променливата е име, закачено към стойност. Основните типове са `int`, `float`, `str`, `bool` и `None`, и между тях преобразуваш явно с `int()`, `float()` и `str()`. Входът от `input()` винаги е низ, затова го преобразуваш, преди да смяташ с него. Десетичните числа имат неточности, а целочисленото деление закръглява надолу. Съобщенията за грешки се четат от последния ред нагоре и казват какво точно не е наред.
