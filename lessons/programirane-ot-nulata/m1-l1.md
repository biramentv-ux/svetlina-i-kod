## Какво ще научиш

## Програмата стига до кръстопът
Досега програмите ни вървяха отгоре надолу, ред след ред, без да се замислят. Истинските програми обаче вземат решения („ако е под 18 – откажи“) и повтарят действия („питай, докато въведеш правилно“). Тези две неща се наричат **управление на потока (control flow)** и правят от списъка с инструкции нещо, което прилича на мислене.

Аналогията е със сутрешната рутина. „Ако вали, взимам чадър, иначе – слънчеви очила“ е условие. „Бъркай кафето, докато захарта се разтвори“ е цикъл. Python има точно по една конструкция за всяка от тези идеи.

## Условия: if, elif, else
Най-простата форма е „ако…, тогава…“:

```python
temp = int(input("Температура: "))
if temp >= 30:
    print("Горещо")
elif temp >= 20:
    print("Топло")
elif temp >= 10:
    print("Прохладно")
else:
    print("Студено")
```

Пуснах програмата четири пъти с входове 35, 22, 12 и 3 и получих съответно „Горещо“, „Топло“, „Прохладно“ и „Студено“.

Как работи. Python проверява условията **отгоре надолу** и изпълнява блока на първото вярно. Останалите се прескачат. `elif` е съкратено от „else if“ („иначе, ако“), а `else` хваща всичко, което не е уловено по-горе. `elif` и `else` са по желание; можеш да имаш само `if`.

### Отстъпът е синтаксис
След двоеточието на реда с `if` идва **блок** – редовете, които принадлежат на условието. В Python те се отбелязват с отстъп (indentation), обикновено четири интервала. В други езици за това служат фигурни скоби, но тук самото подравняване казва кое към кое принадлежи.

Практически правила:
- Всички редове в един блок имат един и същ отстъп.
- Не смесвай табулатори и интервали. Добрите редактори слагат интервали, когато натиснеш Tab; настрой го веднъж.
- Забравеното двоеточие или отстъпът пораждат `SyntaxError` или `IndentationError`. Прочети съобщението – то обикновено сочи точния ред.

### Логически оператори и верижни сравнения
Условията често се състоят от няколко части. Комбинираш ги с `and` („и двете“), `or` („поне едно“) и `not` („обратното“):

```python
age = 17
has_ticket = True
if age >= 18 and has_ticket:
    print("Влизаш")
elif age < 18 and has_ticket:
    print("Само с придружител")
else:
    print("Без билет не може")
n = 14
print("четно" if n % 2 == 0 else "нечетно")
print(1 < n < 20)
word = "кафе"
print("а" in word, "ф" in word)
```

```
Само с придружител
четно
True
True True
```

Три полезни неща в този пример:
- **Едноредово условие:** `A if условие else B` е израз, който връща едно от две неща. Удобно е за кратки избори, но не го насилвай за сложни неща.
- **Верижно сравнение:** `1 < n < 20` се чете като в математиката – „n е между 1 и 20“. Не се налага да пишеш `n > 1 and n < 20`.
- **Оператор `in`:** пита „съдържа ли се?“. Работи с низове и – както ще видим в следващия урок – със списъци.

И още една особеност: `and` и `or` спират да смятат веднага щом отговорът е ясен (**късо съединение**). В `a and b`, ако `a` е лъжа, `b` дори не се проверява. Това ще ти потрябва, когато проверяваш първо дали нещо съществува и после го ползваш.

## Цикъл for: за всеки елемент
Цикълът `for` взема поредица и изпълнява блока веднъж за всеки елемент. Най-често ще го ползваш с `range()`, което произвежда поредица от цели числа:

```python
for i in range(5):
    print(i, end=" ")
print()
print(list(range(2, 10, 3)))
print(list(range(3, 0, -1)))
for letter in "Ива":
    print(letter)
total = 0
for n in range(1, 11):
    total += n
print("Сума:", total)
```

```
0 1 2 3 4 
[2, 5, 8]
[3, 2, 1]
И
в
а
Сума: 55
```

Обърни внимание на `range`:
- `range(5)` дава 0, 1, 2, 3, 4 – **краят не се включва**, а броенето започва от нула.
- `range(2, 10, 3)` е „от 2 до 10 (без 10), със стъпка 3“.
- Отрицателна стъпка брои назад: `range(3, 0, -1)`.
- Сложих `list(...)` само за да видиш числата; в цикъл обикновено го пишеш директно.

Параметърът `end=" "` на `print` казва „не минавай на нов ред, а сложи интервал“. Низът също е поредица от символи, затова `for letter in "Ива"` обхожда буква по буква.

Шаблонът с `total` е един от най-важните в програмирането: **натрупване**. Започваш с неутрална стойност (нула за сбор) и във всяка стъпка добавяш към нея.

## Цикъл while: докато условието е вярно
Когато не знаеш предварително колко пъти ще повториш, ползваш `while`. Той проверява условие преди всяка стъпка и спира, когато стане невярно:

```python
count = 3
while count > 0:
    print("Остават", count)
    count -= 1
print("Старт!")
```

```
Остават 3
Остават 2
Остават 1
Старт!
```

Критично е да **променяш нещо в цикъла**, което в крайна сметка прави условието невярно. Ако забравиш `count -= 1`, условието `count > 0` е вярно завинаги и програмата се върти безкрайно. Ако това се случи, в терминала спираш програмата с Ctrl+C.

Кога `for` и кога `while`? Ако обхождаш известна поредица или броиш определен брой пъти – `for`. Ако повтаряш „докато нещо се случи“ (потребителят въведе верен отговор, играта свърши) – `while`.

### break и continue
Два оператора променят хода на цикъла:
- `break` – излиза веднага от цикъла.
- `continue` – прескача останалото в тази стъпка и преминава към следващата.

```python
for n in range(1, 8):
    if n % 2 == 0:
        continue
    if n > 5:
        break
    print("число", n)
```

```
число 1
число 3
число 5
```

Четните числа се прескачат с `continue`, а когато стигнем 7, `break` прекъсва цикъла – затова 7 не се отпечатва. Често ще срещнеш и конструкцията „безкраен цикъл с изход“:

```python
while True:
    word = input("Парола (стоп за изход): ")
    if word == "стоп":
        break
    print("Получих:", word)
```

С въведени „ала“, „бала“, „стоп“ програмата отпечата „Получих: ала“, „Получих: бала“ и излезе. `while True` изглежда страшно, но е напълно нормален начин да кажеш „повтаряй, докато вътре някой каже `break`“.

### else към цикъл
Python има рядка, но полезна възможност: `else` след цикъла се изпълнява, **само ако цикълът е свършил без `break`**:

```python
for i in range(3):
    print(i)
else:
    print("край")
```

Изходът е 0, 1, 2 и „край“. Ще ползваме това в играта: ако цикълът свърши без налучкване, значи опитите са свършили.

## Стъпка по стъпка: играта „Познай числото“
Програмата си намисля число от 1 до 100, а играчът има 7 опита. След всеки опит получава подсказка „по-голямо“ или „по-малко“.

1. Внеси модула `random` с `import random` – вграден е в Python и не се инсталира.
2. Намисли число: `secret = random.randint(1, 100)`. Функцията връща случайно цяло число, като **двата края са включени**.
3. Заведи броячи: `max_tries = 7` и `tries = 0`.
4. Направи цикъл `while tries < max_tries`, който прочита отговор, увеличава `tries` и сравнява с `secret`.
5. При верен отговор кажи на играча колко опита са му трябвали и излез с `break`.
6. Ако цикълът свърши, без да е достигнат `break`, `else` към него обявява загубата.
7. Защити входа: ако текстът не е цяло число, помоли за друг и не броя опита.

Ето цялата програма, която запази като `game.py`:

```python
import random

secret = random.randint(1, 100)
max_tries = 7
tries = 0
print("Мисля си число от 1 до 100. Имаш 7 опита.")

while tries < max_tries:
    text = input(f"Опит {tries + 1}: ")
    if not text.isdigit():
        print("Моля, въведи цяло число.")
        continue
    guess = int(text)
    tries += 1
    if guess < secret:
        print("По-голямо.")
    elif guess > secret:
        print("По-малко.")
    else:
        print(f"Позна за {tries} опита!")
        break
else:
    print(f"Загуби. Числото беше {secret}.")
```

Тъй като числото е случайно, за да получа повторяем изход при проверка, задавах семе на генератора с `random.seed(5)` преди пускането. С това семе числото е 80, а аз въведох 50, „абв“, 75, 85, 80:

```
Мисля си число от 1 до 100. Имаш 7 опита.
Опит 1: По-голямо.
Опит 2: Моля, въведи цяло число.
Опит 2: По-голямо.
Опит 3: По-малко.
Опит 4: Позна за 4 опита!
```

(Отговорите са подадени през канал, затова не се виждат след „Опит 1:“; на твоя екран ще ги виждаш.) Забележи как „абв“ не изяде опит: `continue` върна цикъла в началото, преди `tries += 1`.

Със семе 11 числото е 58. Като въведох 1, 2, 3, 4, 5, 6, 7, програмата отговаряше „По-голямо.“ седем пъти и накрая написа:

```
Загуби. Числото беше 58.
```

Тази част идва от `else` към `while`: цикълът свърши, защото `tries` достигна 7, без да мине през `break`.

Интересно е да знаеш, че най-добрата стратегия е да делиш интервала на две: започваш от 50, после 25 или 75 и така нататък. Със 7 опита това гарантира налучкване на число до 100, защото 2 на степен 7 е 128. Това е идеята на двоичното търсене, което ще срещнеш по-късно.

## Пример от практиката
Да кажем, че правиш малък скрипт, който проверява паролата на потребител. Разрешени са три опита, а при всеки грешен програмата казва колко остават:

```python
correct = "тайна"
for attempt in range(1, 4):
    answer = input("Парола: ")
    if answer == correct:
        print("Достъп разрешен.")
        break
    print(f"Грешна парола. Остават {3 - attempt} опита.")
else:
    print("Достъпът е блокиран.")
```

Със входове „а“, „б“, „в“ програмата отпечата три пъти „Грешна парола“ (с „Остават 2 опита“, „Остават 1 опита“ и „Остават 0 опита“) и накрая „Достъпът е блокиран.“, а със „а“ и „тайна“ – една грешка и „Достъп разрешен.“ Схемата е същата като в играта: ограничен брой опити, `break` при успех, `else` при провал. Паролата е написана в кода само за урока. В реална програма никога не държиш пароли в изходния текст.

Същата идея – „опитай няколко пъти и спри при успех“ – ще срещнеш, когато програма изпраща заявка към ИИ услуга и я повтаря, ако връзката се е прекъснала.

## Чести грешки
- **`=` вместо `==` в условие** – `if x = 5:` е синтактична грешка. Сравнението е `==`.
- **Липсващо двоеточие след `if`, `for`, `while`** – Python ще ти покаже `SyntaxError`. Всеки ред, който отваря блок, завършва с `:`.
- **Различен отстъп в един блок** – води до `IndentationError`. Подравнявай с четири интервала.
- **Безкраен `while`** – забравена промяна на променливата в условието. Спри с Ctrl+C и провери какво се променя в цикъла.
- **Грешка с единица в `range`** – `range(1, 10)` не включва 10. Ако искаш 1–10, пиши `range(1, 11)`.
- **`if` вместо `elif`** – при поредица от отделни `if` могат да се изпълнят няколко блока, а не само един. Когато вариантите се изключват, ползвай `elif`.
- **`input()` без преобразуване** – `input()` връща низ; `"7" > 5` е `TypeError`. Преобразувай с `int()`.
- **`isdigit()` и отрицателните числа** – `"-5".isdigit()` е `False`. За играта е точно това, което искаме, но запомни го за други програми.

## Упражнение
Подобри играта „Познай числото“:
1. Играчът избира трудност в началото: лесно (10 опита), средно (7) или трудно (5).
2. Когато играчът познае, програмата пита „Пак ли?“ и започва нова игра при отговор „да“.
3. Ако загуби, показва числото. Ако спечели с 1–3 опита, добавя похвала.
4. Брой победи и загуби се натрупва в две променливи и се показва в края.

Критерии за самопроверка:
- няма повтарящ се код, който можеш да скриеш в цикъл;
- невалиден вход („абв“) не изяжда опит и не срива програмата;
- безкрайният цикъл за „пак ли?“ има ясен изход с `break`;
- можеш да обясниш на глас защо `else` към `while` се изпълнява само при загуба.

Бонус: избери сам най-добрата стратегия и пресметни колко опита най-много са нужни за интервал 1–1000.

## Бърза справка

| Задача | Запис |
|---|---|
| Условие | `if x > 0:` / `elif ...:` / `else:` |
| Логика | `and`, `or`, `not` |
| Верижно сравнение | `0 < x < 10` |
| Принадлежност | `"а" in text` |
| Едноредово условие | `a if cond else b` |
| Цикъл по брой | `for i in range(n):` |
| Диапазон със стъпка | `range(start, stop, step)` |
| Цикъл по условие | `while cond:` |
| Изход / прескок | `break` / `continue` |
| Else към цикъл | изпълнява се, ако не е имало `break` |
| Случайно число | `random.randint(a, b)` (двата края са включени) |
| Спиране на безкраен цикъл | Ctrl+C в терминала |

## Обобщение
Условията `if`, `elif` и `else` избират точно един блок, а границите на блока се определят от отстъпа. Цикълът `for` обхожда поредица, често с `range()`, чийто край не се включва. Цикълът `while` повтаря, докато условието е вярно, затова вътре трябва нещо да го променя. `break` излиза от цикъла, `continue` прескача стъпка, а `else` към цикъл се изпълнява при липса на `break`. С тези неща написа цяла игра с ограничени опити и проверка на входа.
